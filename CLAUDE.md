## Versioning

Version format: `MAJOR.MINOR.PATCH-beta` (stored in `package.json`, displayed via `src/lib/match-fit-product-version.ts`).

- **MAJOR** (1st digit): Big breaking changes or major product milestones
- **MINOR** (2nd digit): Smaller changes and new features
- **PATCH** (3rd digit): Bug fixes and small UI changes

Current version: `1.1.2-beta`
